Theory: Graph Algorithms

A graph is a set of nodes (vertices) connected by edges. This lab uses one 8-node graph rendered two ways: a weighted undirected version (for MST and Dijkstra) and a directed acyclic version — a DAG — (for Topological Sort).

Topological Sort

Orders the nodes of a Directed Acyclic Graph (DAG) so that every directed edge u→v places u before v. This lab uses Kahn's algorithm: compute in-degree of every node, repeatedly dequeue a node with in-degree 0, append it to the result, and decrement its neighbors' in-degree — re-enqueueing any neighbor whose in-degree drops to 0. Topological sort is undefined on graphs with cycles — Kahn's algorithm detects this when the result has fewer nodes than the graph.

Minimum Spanning Tree (Prim's)

A spanning tree connects all nodes using the fewest possible edges (n-1) with no cycles; the minimum spanning tree does so with the least total edge weight. Prim's algorithm grows one tree from a start node: at every step it looks at every "frontier" edge (tree node → non-tree node) and greedily adds the cheapest one, until all nodes are included.

Dijkstra's Shortest Path

Finds the shortest distance from a source node to every other node in a graph with non-negative weights. Maintains a tentative distance for every node (0 for the source, ∞ elsewhere). Repeatedly visits the unvisited node with the smallest tentative distance and relaxes its outgoing edges — updating a neighbor's distance if going through the current node is shorter.

V = number of vertices, E = number of edges. This lab's linear-scan implementation of Prim's and Dijkstra's is O(V²), matching the "pick smallest of the unvisited" description used in the simulation.

Simulator Procedure

  1. Open the Simulation tab and choose an algorithm: Topological Sort, Prim's MST, or Dijkstra's Shortest Path.
  2. Selecting Topological Sort automatically switches the graph view to the directed DAG version; MST/Dijkstra use the weighted undirected version.
  3. For Prim's or Dijkstra's, pick a Start / Source Node from the dropdown.
  4. Click Start Simulation, then Step through each stage or click Run All to animate automatically.
  5. Watch the SVG graph: nodes/edges highlight amber while being considered, then turn emerald once confirmed (added to the MST / topological order / shortest-path tree).
  6. The side panel tracks live state — in-degrees, frontier edges, running MST weight, or tentative distances — depending on the algorithm.
  7. Click Reset to clear the trace and start over with the same graph.
