Theory: AVL Trees

A plain Binary Search Tree (BST) can degrade into a linked list (O(n) lookups) if values are inserted in sorted order. An AVL tree (Adelson-Velsky & Landis) is a self-balancing BST that fixes this by re-shaping itself after every insertion so the tree height always stays O(log n).

Balance Factor

For any node, balanceFactor = height(leftSubtree) − height(rightSubtree). An AVL tree requires every node's balance factor to stay in {-1, 0, +1}. A leaf has height 1 (or 0 for an empty subtree, by convention here empty = height 0).

Why Rotations Are Needed

Inserting a new value can push a node's balance factor to +2 or −2, violating the AVL property and threatening O(log n) height. A rotation locally restructures the three nodes involved to bring the balance factor back within {-1,0,1} without breaking the BST ordering property.

The Four Rotation Cases

Left-Left (LL) — balance factor > 1 and the new value went into the left child's left subtree. Fix: single Right Rotation at the unbalanced node.
Right-Right (RR) — balance factor < −1 and the new value went into the right child's right subtree. Fix: single Left Rotation at the unbalanced node.
Left-Right (LR) — balance factor > 1 and the new value went into the left child's right subtree. Fix: Left Rotation on the left child, then Right Rotation on the node (a "double rotation").
Right-Left (RL) — balance factor < −1 and the new value went into the right child's left subtree. Fix: Right Rotation on the right child, then Left Rotation on the node (a "double rotation").

A plain BST degrades to O(n) when values are inserted in sorted order (it becomes a linked list). AVL's rotations guarantee height stays within ~1.44·log₂(n+2), keeping every operation O(log n).

Simulator Procedure

  1. Open the Simulation tab. Type a comma-separated list of integers to insert, or click a Quick Preset.
  2. Click Start Simulation to reset the tree and load your insertion queue.
  3. Click Step to insert the next value — watch it descend to its BST position, then watch the tree instantly rebalance (rotate) if a balance factor exceeded ±1.
  4. Or click Run All to insert every queued value automatically, one at a time.
  5. Each node in the tree diagram shows its value, height, and balance factor (bf). Nodes never display a balance factor outside {-1, 0, 1} once a step completes — that's the AVL invariant in action.
  6. The Output Terminal logs the descent path and names the exact rotation case (LL / RR / LR / RL) whenever one triggers.
  7. Click Reset to clear the tree and start a fresh sequence.
