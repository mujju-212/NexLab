Theory: String Algorithms

This lab covers two classic string data structures/algorithms: the Trie (a tree for fast prefix lookups) and KMP (Knuth-Morris-Pratt, a linear-time exact pattern-matching algorithm).

Trie (Prefix Tree)

Each node holds a map of children (character → node) and an isEndOfWord flag. Inserting a word walks/creates one node per character from the root; searching a prefix walks the same path — if it exists, the prefix is present (whether or not it's a complete word).

KMP Pattern Matching

Naive string matching restarts from scratch after every mismatch — wasteful. KMP precomputes an LPS array (Longest proper Prefix which is also a Suffix, per pattern position) so that on a mismatch, it can jump the pattern pointer directly to the next viable alignment instead of re-comparing characters it already knows match.

Understanding the LPS Array

For pattern "ABABCABAB", the LPS array is [0,0,1,2,0,1,2,3,4]. lps[i] is the length of the longest prefix of the pattern that is also a suffix of pattern[0..i]. When a mismatch happens at pattern index j, KMP doesn't restart — it sets j = lps[j-1], reusing the already-matched suffix as the new prefix to compare from. Crucially, the text pointer i never moves backward.

Simulator Procedure

  1. Open the Simulation tab and choose a mode: Trie (Prefix Tree) or KMP Pattern Matching.
  2. Trie mode: type comma-separated words (or use a preset), click Start Simulation, then Step or Run All to insert them one at a time and watch the tree grow. Use the Search Prefix box to highlight a path and see how many stored words share it.
  3. KMP mode: enter a Text and a Pattern, click Start Simulation, then Step through each comparison or Run All to animate the full search. The LPS table is shown above the comparison row.
  4. Watch the pattern slide beneath the text as its alignment (offset i - j) changes — on a mismatch it jumps using the LPS table instead of restarting from the next text character.
  5. All match positions are listed in the result banner once the run finishes.
  6. Click Reset at any time to clear the current mode's state.
