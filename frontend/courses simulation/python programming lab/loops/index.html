Theory: Loops, Iteration & Control Flow

Loops let a program repeat a block of code without rewriting it. Python has two loop constructs — for (iterate over a known sequence) and while (repeat while a condition holds) — plus keywords that alter their flow.

for i in range(a, b, step)

Iterates i from a up to (not including) b, moving by step (default 1). range(1,6) → 1,2,3,4,5.

while condition:

Repeats the body as long as condition is True. The body must eventually make the condition False, or the loop never ends (infinite loop).

continue

Skips the rest of the current iteration's body and jumps straight back to the loop's condition/next item — the loop keeps running.

break

Exits the loop immediately, regardless of the condition or remaining items. Code after the loop resumes normally.

for ... else:

The else block on a loop runs only if the loop finished without hitting break — useful for "search and report not-found" patterns.

Nested loops

A loop inside another loop. The inner loop completes fully for every single iteration of the outer loop — this is how grids/tables are built.

Common Loop Patterns Covered in This Lab

Accumulation — Sum 1..N, Factorial N (running total/product each iteration).
Conditional repetition — While Count to N (condition-driven, not count-driven).
Filtering — Sum of Evens (uses continue to skip odd numbers).
Composition — Multiplication Table (nested loops).
Searching — Find First Multiple of 7 (uses break and for...else).
