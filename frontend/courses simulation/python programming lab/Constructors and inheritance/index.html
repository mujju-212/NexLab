Theory: Constructors & Inheritance

Constructors initialize a newly created object's starting state. Inheritance lets a child class reuse, extend, or override behavior defined in a parent class — the foundation of code reuse in object-oriented design.

__init__ Constructor Initializer

def __init__(self, ...) runs automatically the moment an object is instantiated, to set initial instance attributes.

Class Inheritance Child(Parent)

A child class inherits attributes/methods using class Child(Parent):, enabling reuse and modularity.

super() super().__init__()

super() lets a child class explicitly invoke the parent's constructor/methods without hardcoding the parent's name.

ScenarioWhat HappensExample

Common Pitfalls

  • Overriding __init__ silently drops the parent's setup unless you explicitly call super().__init__(...) — a very common source of missing attributes.
  • self must be the first parameter of every instance method, including __init__ — Python passes it automatically, you never pass it yourself when calling.
  • Mutable default arguments (e.g. def __init__(self, items=[]):) are created ONCE and shared across all instances — always default to None and create the list inside the method instead.
  • super() respects Method Resolution Order (MRO), not just "the direct parent" — this matters once multiple inheritance is involved.
