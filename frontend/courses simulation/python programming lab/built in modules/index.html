Theory: Python Built-in Modules

A module is a pre-written .py file containing functions, constants, and classes that can be reused with an import statement. Python ships with a large standard library of built-in modules that require no external installation.

math Math Tools

Advanced mathematical constants and functions: math.sqrt(x), math.factorial(x), math.pi, math.pow(x,y).

random PRNG

Pseudo-random numbers and selections: random.randint(a,b), random.choice(seq), random.random().

datetime Dates & Time

Date and time handling: datetime.date.today(), datetime.now(), and date arithmetic.

Common Pitfalls

  • Don't shadow module names. Naming your own file or variable random.py or math breaks the real import.
  • random.random() vs random.randint(): random() returns a float in [0.0, 1.0), while randint(a,b) returns an int in [a, b] — both endpoints inclusive.
  • Wildcard imports (from module import *) pollute the namespace and make it unclear where a name came from — avoid in real projects.
  • datetime.datetime.now() vs datetime.date.today(): the former includes time-of-day, the latter is date-only — easy to confuse the nested module/class name datetime.datetime.
