            <h2 class="text-xl font-bold text-indigo-400 border-b border-slate-700 pb-2">Theory: Data Preprocessing & Feature Engineering</h2>
            <p class="text-sm text-slate-300 leading-relaxed">
                Raw real-world datasets often contain missing values, categorical string features, and unscaled numerical variables with vast dynamic ranges. <strong>Data Preprocessing</strong> transforms dirty raw data into a clean matrix suitable for machine learning algorithms.
            </p>

            <div class="grid grid-cols-1 md:grid-cols-3 gap-4 text-sm">
                
                <div class="bg-slate-900 p-4 rounded-lg border border-slate-700 space-y-2">
                    <h3 class="font-bold text-indigo-300 font-mono flex items-center justify-between">
                        <span><i class="fa-solid fa-filter-circle-xmark text-emerald-400"></i> 1. Missing Value Imputation</span>
                        <span class="text-[10px] bg-emerald-500/20 text-emerald-300 px-2 py-0.5 rounded font-sans">SimpleImputer</span>
                    </h3>
                    <p class="text-slate-400 text-xs leading-relaxed">
                        Replaces missing <code class="text-amber-300">NaN</code> cells using column statistics: <strong>Mean</strong> (for continuous Gaussian features) or <strong>Median</strong> (robust against extreme outliers).
                    </p>
                </div>

                <div class="bg-slate-900 p-4 rounded-lg border border-slate-700 space-y-2">
                    <h3 class="font-bold text-indigo-300 font-mono flex items-center justify-between">
                        <span><i class="fa-solid fa-barcode text-amber-400"></i> 2. Categorical Encoding</span>
                        <span class="text-[10px] bg-amber-500/20 text-amber-300 px-2 py-0.5 rounded font-sans">OneHot / Label</span>
                    </h3>
                    <p class="text-slate-400 text-xs leading-relaxed">
                        Converts string labels into numbers. <strong>One-Hot Encoding</strong> expands nominal features into binary columns ($0$ or $1$) to avoid artificial ordinal bias.
                    </p>
                </div>

                <div class="bg-slate-900 p-4 rounded-lg border border-slate-700 space-y-2">
                    <h3 class="font-bold text-indigo-300 font-mono flex items-center justify-between">
                        <span><i class="fa-solid fa-sliders text-cyan-400"></i> 3. Feature Scaling</span>
                        <span class="text-[10px] bg-cyan-500/20 text-cyan-300 px-2 py-0.5 rounded font-sans">MinMax / Standard</span>
                    </h3>
                    <p class="text-slate-400 text-xs leading-relaxed">
                        <strong>StandardScaler</strong> converts features to $\mu=0, \sigma=1$: $x' = \frac{x - \mu}{\sigma}$. <strong>MinMaxScaler</strong> bounds values to $[0, 1]$: $x' = \frac{x - x_{min}}{x_{max} - x_{min}}$.
                    </p>
                </div>

            </div>

            <div class="bg-slate-900/60 p-4 rounded-lg border border-slate-700 text-xs text-slate-300 space-y-2">
                <h4 class="font-bold text-indigo-300 text-sm"><i class="fa-solid fa-circle-info text-amber-300"></i> Why Feature Scaling is Essential</h4>
                <p class="text-slate-400">
                    Distance-based ML algorithms (like k-NN, SVM, Gradient Descent, or Neural Networks) are sensitive to feature scales. If Age ranges from $18-65$ and Salary ranges from $\$20,000-\$150,000$, Salary will completely dominate the distance calculations unless scaled!
                </p>
            </div>
        </div>
