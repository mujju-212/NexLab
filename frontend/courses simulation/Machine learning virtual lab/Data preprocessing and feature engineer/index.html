Theory: Data Preprocessing & Feature Engineering

Raw real-world datasets almost always contain missing values, categorical text fields, and numerical columns with wildly different scales. Data Preprocessing converts this dirty raw data into a clean numeric matrix that a machine learning estimator can actually train on. Every transformation below follows the same Scikit-Learn contract: fit() learns statistics from training data, transform() applies them.

SimpleImputer

Replaces missing NaN cells using a column statistic: Mean (Gaussian-like columns) or Median (robust to outliers/skew). Never impute using statistics from the test set — always fit on training data only.

One-Hot Encoding

Expands a nominal (unordered) string column into $k$ binary $\{0,1\}$ columns — one per category — so the model never assumes a false numeric order like France=0 < India=1 < Spain=2.

Feature Scaling

StandardScaler: $x' = \dfrac{x - \mu}{\sigma}$ (mean 0, std 1). MinMaxScaler: $x' = \dfrac{x - x_{min}}{x_{max} - x_{min}}$ (bounded to $[0,1]$).

z = (x − μ) / σ   where μ = sample mean, σ = sample standard deviation (population, ddof=0 — matches sklearn's StandardScaler)

Why Feature Scaling Is Essential

Distance-based and gradient-based algorithms (k-NN, SVM, Gradient Descent, Neural Networks) are sensitive to feature magnitude. If Age ranges 18–65 and Salary ranges $20,000–$150,000, Salary will dominate every distance calculation and every gradient step unless both are scaled to comparable ranges. Tree-based models (Decision Trees, Random Forest) are scale-invariant and do not require this step.

Worked Example — Standardizing the Age Column

Imputed Age values: [34, 27, 35.5, 42, 39]. Mean μ = 35.5. Deviations: [-1.5, -8.5, 0, 6.5, 3.5]. Variance = (1.5² + 8.5² + 0² + 6.5² + 3.5²) / 5 = 25.8, so σ = √25.8 ≈ 5.08. z-score for the first row: (34 − 35.5) / 5.08 ≈ -0.295. The simulator below computes this live for every row — it is not a hardcoded lookup.
