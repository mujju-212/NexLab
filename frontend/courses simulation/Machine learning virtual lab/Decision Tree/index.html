Theory: Decision Tree Classification & Impurity Metrics

A Decision Tree recursively splits data into subsets based on feature thresholds, forming a flowchart of internal decision nodes and leaf nodes holding class predictions. The split at every node is chosen to reduce impurity as much as possible.

Shannon Entropy H(S)

$H(S) = -\sum p_i \log_2(p_i)$. A 50/50 binary split has $H=1.0$ (max impurity); a pure node has $H=0.0$.

Information Gain

$IG(S,A) = H(S) - \sum \frac{|S_v|}{|S|}H(S_v)$ — the entropy reduction from splitting on feature $A$.

Gini Impurity G(S)

$G(S) = 1 - \sum p_i^2$. Cheaper to compute than entropy (no logarithms) and is sklearn's default criterion.

For a 50/50 binary split: H = −(0.5·log&sub2;0.5 + 0.5·log&sub2;0.5) = −(0.5×(−1) + 0.5×(−1)) = 1.0  |  G = 1 − (0.5²+0.5²) = 0.5

Overfitting & Pruning

Unconstrained trees can grow deep enough to perfectly fit every training sample (100% training accuracy, poor generalization). max_depth, min_samples_split, and cost-complexity pruning keep the tree shallow and robust.

Entropy Must Always Match the Class Counts

A node showing values: [5, 5] MUST display entropy exactly $1.0$ — there is no other mathematically valid answer for a perfect 50/50 binary split. This simulator computes entropy and Gini directly from each node's class-count array every time it renders, so this can never drift out of sync again.

Simulator Procedure

  1. Select a Dataset (Play Tennis Weather, Credit Loan Default, or Iris Subset) or click a Quick Preset.
  2. Choose the splitting Criterion (Gini or Entropy) and Max Depth (1–3).
  3. Click Start Simulation to load the dataset and build the root node.
  4. Click Step Epoch to trace tree construction line-by-line and watch nodes split.
  5. Inspect each node's genuinely computed impurity value and class-count array — try switching Gini ↔ Entropy and verify the numbers always agree with the shown [class0, class1] counts.
  6. Click Run / Execute All to finish tree construction instantly.
