Theory: Binary Classification & Logistic Regression

Logistic Regression is a supervised algorithm for binary classification where the target $y \in \{0,1\}$. Unlike Linear Regression, which outputs unbounded continuous values, Logistic Regression squashes a linear combination of inputs through the Sigmoid function to produce a probability strictly between 0 and 1.

σ(z) = 1 / (1 + e−z)   where z = w·x + b

Sigmoid Function

Maps any real number to $P(y=1|x) \in [0,1]$. At $z=0$, $\sigma(z)=0.5$ — this is the decision boundary point.

Decision Boundary

Default probability threshold is 0.5: &yhat; = 1 if P ≥ 0.5 else 0. Adjustable to trade off Precision vs Recall.

Log-Loss

Convex cost penalizing confident wrong predictions: J = -1/n Σ[y·log(&yhat;) + (1-y)·log(1-&yhat;)].

Why Linear Regression Fails for Classification

Linear Regression outputs unbounded predictions ($>1$ or $<0$) and is highly sensitive to outliers, which shifts the decision boundary unpredictably. Logistic Regression guarantees a valid probability output in $[0,1]$ and is trained by minimizing the convex Log-Loss rather than MSE.

A Note on the Demo Weights

The sigmoid, log-loss, and accuracy/precision/recall computations in this simulator are all genuinely computed live from the current w, b, and threshold. The specific final w, b values shown for each preset dataset are illustrative approximations of what LogisticRegression.fit() would converge to on that toy data — chosen to produce a clean-looking decision boundary for teaching, not derived from a full iterative solver. All downstream metrics (log-loss, accuracy, precision, recall) are always mathematically consistent with whatever w, b, and threshold are active, so changing the threshold slider always changes the numbers correctly.
