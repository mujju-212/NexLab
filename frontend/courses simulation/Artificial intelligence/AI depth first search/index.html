Theory: Depth-First Search

Depth-First Search (DFS) explores a graph by always diving as deep as possible along one branch before backtracking. It is implemented with an explicit stack (Last-In-First-Out) holding nodes still to be visited, plus a visited set to avoid revisiting.

stack ← [start]
visited ← {}
while stack is not empty:
  node ← stack.pop()
  if node not in visited:
    mark node visited; record in DFS order
    for each neighbour of node (in reverse adjacency order):
      if neighbour not visited: stack.push(neighbour)

Neighbours are pushed in reverse adjacency order so that, once popped (LIFO), they come out in the ORIGINAL left-to-right adjacency order — this is purely a bookkeeping detail to make traversal order predictable and match how DFS is usually hand-traced. When every neighbour of the current node has already been visited, the next pop() naturally returns an earlier, unfinished branch — this is backtracking, and it falls out of the stack automatically with no extra code.

Worked Micro-Example

Graph: A→{B,C}, B→{D}, C→{} (D and C are dead ends). Start at A.

stack=[A] → pop A, visit A, push C,B (reversed) → stack=[C,B]
pop B, visit B, push D → stack=[C,D]
pop D, visit D, no unvisited neighbours → stack=[C]
pop C, visit C, no unvisited neighbours → stack=[]
Order: A, B, D, C

Notice D is a dead end — after visiting it, the algorithm doesn't "know" to go back to C explicitly; it simply pops the next item still sitting in the stack (C), which is exactly backtracking.

Depth-First Search (DFS)Breadth-First Search (BFS)
Uses a stack (LIFO) — explores one branch fully before trying the next.Uses a queue (FIFO) — explores all neighbours at the current depth before going deeper.
Memory: O(branching × max depth) — only needs to remember the current path.Memory: O(branchingdepth) — must remember an entire "frontier" layer, which can be huge.
NOT guaranteed to find the shortest path (in edges).Guaranteed to find the shortest path in an unweighted graph.
Complete on finite graphs (with a visited set to avoid infinite loops on cycles).Also complete on finite graphs.

Simulator Procedure

  1. Open the Simulation tab. The 8-node graph is drawn on the left; pick a Quick Preset to choose the start node.
  2. Click Start to push the start node onto the stack.
  3. Click Step Execution repeatedly — each step pops one node from the stack, marks it visited (highlighted on the graph), and pushes its unvisited neighbours.
  4. Watch the Stack panel on the right update live, and edges light up as they're traversed.
  5. Or click Run All to animate the full traversal automatically.
  6. When a node's neighbours are all already visited, the next step visibly "jumps back" to an earlier branch — that's backtracking, visible directly in the stack panel.
  7. The final DFS order is printed in the terminal once the stack empties. Click Reset to try again.
