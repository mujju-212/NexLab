Theory: Value Iteration

Value Iteration solves a Markov Decision Process (MDP) — a grid of states S, actions A, deterministic transitions, a reward function R(s) and a discount factor γ — by repeatedly applying the Bellman optimality update to every state until the value function stops changing.

V(s) ← R(s) + γ · maxa ∈ A V( result(s,a) )

Each full sweep over every state is one iteration. Terminal states (goal / pit) are absorbing: their value is fixed at their reward and never updated further. The algorithm stops when the maximum change across all states in one sweep, Δ = max|Vnew(s) − Vold(s)|, drops below a small threshold ε (e.g. 0.001), or after a maximum iteration cap. Once V has converged, the optimal policy is read off directly: π*(s) = argmaxa V(result(s,a)).

Worked Micro-Example

Consider a cell directly left of the goal (reward +1, terminal) with living reward R(s) = −0.04 and γ = 0.9. Suppose after some sweeps the goal already has converged value V(goal) = 1 (fixed) and all other neighbours currently hold value 0. The Bellman update for this cell picks the best of its 4 possible next-states:

V(s) = −0.04 + 0.9 · max(V(up), V(down), V(left), V(right))
V(s) = −0.04 + 0.9 · max(0, 0, 0, 1) = −0.04 + 0.9 = 0.86

On the next sweep, the neighbour of this cell now sees a non-zero value here and updates too — the "wave" of information propagates backward from the goal one cell per sweep until every reachable state's value reflects the true expected discounted return.

GridWorld Used in This Lab

4×4 deterministic grid

One goal cell (R = +1, terminal), one pit cell (R = −1, terminal), one or two wall cells (impassable), all other cells give a living reward of −0.04 per step. Actions: up / down / left / right. Hitting a wall or the grid edge leaves the agent in place (deterministic, no randomness / "noise").

Why γ = 0.9 matters

The discount factor shrinks the value of far-away rewards, which is what makes the agent prefer short paths to the goal instead of wandering. With γ close to 1 the agent is patient; with γ close to 0 it only cares about immediate reward.

Simulator Procedure

  1. Open the Simulation tab. Pick a grid layout from Quick Presets, or leave the default GridWorld loaded.
  2. Adjust γ (discount) and the convergence threshold ε if you want to see how they change convergence speed.
  3. Click Start to initialise every state's value to 0 (except fixed terminal rewards).
  4. Click Step (1 Sweep) to run one full Bellman update over every state — watch every cell's value pulse and update, and the Δ / iteration counters change.
  5. Or click Run All to sweep automatically and continuously until Δ < ε (convergence) or the iteration cap is hit.
  6. Once converged, the arrow shown in each cell is the optimal action π*(s) = argmaxa V(result(s,a)) read straight off the converged values.
  7. Click Reset to clear all values and start over.
