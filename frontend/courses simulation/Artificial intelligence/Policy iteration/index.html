Theory: Policy Iteration

Policy Iteration solves the same MDP as Value Iteration but works with an explicit policy π the whole time. It alternates two phases until the policy stops changing: Policy Evaluation (compute how good the current policy actually is) and Policy Improvement (make the policy greedy with respect to that evaluation).

// 1. Policy Evaluation (repeat to convergence)

V(s) ← R(s) + γ · V( result(s, π(s)) )

// 2. Policy Improvement (one greedy pass)

π(s) ← argmaxa V( result(s,a) )

Notice Evaluation uses the fixed action π(s) — no max — and is itself an iterative sweep repeated until its own Δ < ε. Improvement then looks at every action's resulting value and greedily switches π(s) to whichever action leads to the highest-value neighbour. If no state's action changed during improvement, the policy is stable — it is provably optimal, and the algorithm stops.

Worked Micro-Example

Start with an arbitrary policy, e.g. π(s) = "right" for every non-terminal cell. Policy Evaluation sweeps V(s) = R(s) + γ·V(result(s,"right")) repeatedly for THIS fixed policy until it converges — even if "right" is a bad choice in some cells, evaluation faithfully computes how much reward you'd actually get by blindly always going right from there.

Then Improvement checks, cell by cell: "given these evaluated values, is 'right' still the best action, or would 'up' or 'left' reach a higher-value neighbour?" Any cell where a better action exists gets switched. Because the policy actually changed, we run Evaluation again on the NEW policy, then Improve again — repeating until a full Improvement pass makes zero changes.

Simulator Procedure

  1. Open the Simulation tab and pick a Quick Preset grid layout.
  2. Click Start — this initialises an arbitrary starting policy (every cell points "right") and V(s)=0.
  3. Click Step (1 Cycle) to run ONE full Evaluate→Improve cycle: watch the value grid converge under the current policy, then the arrows update wherever a better action was found.
  4. Or click Run All to repeat cycles automatically until the policy is stable (no arrow changes in an improvement pass).
  5. The status panel shows how many inner evaluation sweeps ran and whether the last improvement pass changed any actions.
  6. Click Reset to clear the policy/values and start over.
