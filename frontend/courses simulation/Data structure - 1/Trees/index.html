Theory: Binary Search Trees

A Binary Search Tree (BST) is a node-based tree where each node has at most two children, and the BST property holds at every node: everything in the left subtree is smaller than the node's value, and everything in the right subtree is larger. This ordering makes search, insert, and delete efficient.

insert(value)

Starting at the root, compare the new value to the current node. Go left if smaller, right if larger, recursing until an empty spot is found — that's where the new node is attached.

search(value)

Same comparison logic as insert: at each node, go left or right based on comparison, until the value is found or a null branch is reached (not present).

Inorder Traversal (L, Node, R)

Visit left subtree, then the node, then right subtree. For a BST this always produces values in ascending sorted order.

Preorder Traversal (Node, L, R)

Visit the node first, then left subtree, then right. Useful for copying/serializing a tree structure.

Postorder Traversal (L, R, Node)

Visit left subtree, then right subtree, then the node itself. Useful for safely deleting a tree bottom-up.

Balanced vs Skewed

Inserting already-sorted data (e.g. 10,20,30,40) produces a degenerate, "skewed" tree that behaves like a linked list — height O(n) instead of O(log n).

OperationAverage CaseWorst Case (skewed)
InsertO(log n)O(n)
SearchO(log n)O(n)
DeleteO(log n)O(n)
Traversal (any order)O(n)O(n)

Simulator Procedure

  1. Open the Simulation tab. Set Mode to "Insert Values" and type comma-separated numbers (e.g. 50,30,70,20,40,60,80) into the values box, or click a Quick Preset.
  2. Click Start Simulation, then Step to watch each comparison (go left / go right) until the value lands in an empty spot — or click Run All to animate automatically.
  3. The tree diagram updates live with computed positions (depth = row, in-order position = column) and connecting edges.
  4. Switch Mode to "Traverse Tree", pick Inorder, Preorder, or Postorder, and click Start/Run All to animate that traversal over the tree you built — the visited path and output order appear in the terminal.
  5. Click Reset to clear the entire tree and start over.
