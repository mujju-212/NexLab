Theory: Stacks, Queues & Expression Conversion

Stacks and queues are linear structures that restrict where elements can be added/removed, which is exactly what makes them useful for controlling order of processing.

Stack — LIFO

Last In, First Out. push(x) adds to the top, pop() removes from the top, peek() reads the top without removing. Backed by a plain array using its end as "top".

Queue — FIFO

First In, First Out. enqueue(x) adds to the back, dequeue() removes from the front. Backed by a plain array: push() to enqueue, shift() to dequeue.

Infix, Postfix & Operator Precedence

Infix notation (A+B*C) is how humans write expressions — operators sit between operands, and precedence/parentheses determine order. Postfix (Reverse Polish) notation (ABC*+) places operators after their operands, removing all ambiguity — no parentheses or precedence rules are needed to evaluate it, which is why compilers and calculators use it internally.

OperatorPrecedenceAssociativity
^ (power)3 (highest)Right-to-left
* /2Left-to-right
+ -1 (lowest)Left-to-right
Conversion algorithm (operator-precedence / "shunting-yard"): Scan the infix expression left to right using an explicit operator stack. Operands go straight to the output. An operator pops any stack-top operators of higher or equal precedence to the output first, then pushes itself. ( is always pushed; ) pops everything back to the matching (. At the end, pop all remaining operators to the output.
