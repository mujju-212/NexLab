Theory: Searching & Hashing

Searching means locating a target value inside a collection. The right algorithm depends heavily on whether the data is sorted, and hashing offers a completely different strategy — near-instant lookup via a computed address.

Linear Search

Check every element from index 0 onward until a match is found or the array ends. Works on unsorted data — no assumptions about order required.

Binary Search

Requires a sorted array. Compare the target to the middle element; discard the half that can't contain it; repeat on the remaining half. mid = Math.floor((lo+hi)/2).

Hash Function

Converts a key into a bucket index, e.g. sum(charCodes) % numBuckets. A good hash function spreads keys evenly across buckets.

Collision Handling (Chaining)

When two different keys hash to the same bucket (a collision), chaining simply stores both keys in a list at that bucket instead of overwriting.

Why binary search needs sorted data: Discarding half the array only works if we know every element on one side of the midpoint is guaranteed smaller (or larger). That guarantee only holds when the array is sorted — this lab automatically sorts the display array for Binary Search and tells you so.
Algorithm / StructureBest CaseAverage / Worst Case
Linear SearchO(1)O(n)
Binary Search (sorted)O(1)O(log n)
Hash Table insert/search (avg)O(1)O(1) avg, O(n) worst (all collide)

Simulator Procedure

  1. Open Simulation and choose a Mode: Linear Search, Binary Search, or Hash Table.
  2. Linear/Binary Search: enter a comma-separated array and a target value. Binary Search automatically sorts the array first (shown in the terminal) since it requires sorted input.
  3. Hash Table: enter comma-separated keys (words or numbers) and a bucket count. Watch each key's hash get computed and land in a bucket, including a deliberate collision.
  4. Click Start Simulation, then Step through each comparison / hash computation, or Run All to animate automatically.
  5. Compare how few steps Binary Search needs versus Linear Search on the same array size.
  6. Click Reset to try a different array, target, or key set.
