Theory: Graphs & Traversal Algorithms

A graph G = (V, E) is a set of vertices (nodes) connected by edges. Graphs model networks — roads, social connections, dependencies. This lab uses an adjacency list: each vertex stores an array of its directly connected neighbors, which is memory-efficient for sparse graphs.

Breadth-First Search (BFS)

Explores level-by-level using a FIFO queue: enqueue the start node, then repeatedly dequeue a node, visit it, and enqueue any unvisited neighbors. Finds the shortest path (fewest edges) from the source in an unweighted graph.

Depth-First Search (DFS)

Explores as deep as possible before backtracking, using a LIFO stack (or recursion, which uses the call stack implicitly): push the start node, then repeatedly pop a node, visit it, and push its unvisited neighbors.

Key insight this lab demonstrates: Running BFS and DFS from the same start node on the same graph produces different visitation orders — the queue (BFS) spreads outward level by level, while the stack (DFS) dives down one branch fully before backtracking.
OperationTime ComplexitySpace Complexity
BFS (adjacency list)O(V + E)O(V) — queue + visited set
DFS (adjacency list)O(V + E)O(V) — stack + visited set
Edge lookup (adjacency list)O(degree of V)O(V + E) total storage

Data Structures Used

Queue (BFS) — real FIFO array: queue.push(x) to enqueue at the back, queue.shift() to dequeue from the front.
Stack (DFS) — real LIFO array: stack.push(x) to push, stack.pop() to pop from the same end.

Simulator Procedure

  1. Open the Simulation tab. The 8-node graph (A–H) is drawn as a diagram with fixed positions and labeled edges.
  2. Choose an Algorithm (BFS or DFS) and a Start Node from the dropdowns, or click a Quick Preset.
  3. Click Start Simulation to build the trace, then Step through one operation at a time (dequeue/pop, visit, enqueue/push).
  4. Or click Run All to animate automatically. Watch the current node pulse, the Queue/Stack panel change, and visited nodes turn green.
  5. Compare: run BFS then DFS from the same start node and note how the final traversal order in the terminal differs.
  6. Click Reset to clear the trace and try another combination.
