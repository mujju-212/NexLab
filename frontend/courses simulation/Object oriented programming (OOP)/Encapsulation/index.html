Theory: Encapsulation

Encapsulation bundles data (attributes) and the methods that operate on it into a single unit (a class), and restricts direct outside access to that data — typically forcing interaction through controlled getter/setter methods.

Java

Uses private, protected, public keywords. Private members trigger a real compile-time error if accessed from outside the class.

Python

Uses naming convention only: _protected, __private. Python does not truly enforce privacy — see the nuance below.

C++

Uses access specifiers (private:, public:) inside the class block, enforced at compile time.

Important nuance: Python's "privacy" is name mangling, not enforcement

Writing self.__balance inside a class does not make the attribute truly inaccessible. Python performs name mangling: internally it renames the attribute to _ClassName__balance. So account.__balance from outside raises AttributeError (no attribute exists under that literal name) — but the data is still reachable via account._Account__balance. Java and C++, by contrast, enforce privacy for real at compile time.

Encapsulation Syntax — Multi-Language

Java

class Account {
  private double balance;
  public double getBalance() {
    return balance;
  }
  public void setBalance(double b) {
    balance = b;
  }
}

Python

class Account:
    def __init__(self):
        self.__balance = 0

    def get_balance(self):
        return self.__balance

C++

class Account {
  private:
    double balance;
  public:
    double getBalance() { return balance; }
};

Simulator Procedure

  1. Open the Simulation tab and select a language pill — Java, Python, or C++.
  2. Study how the private balance attribute is exposed only through a public getter method.
  3. Click Access via Getter to see the correct, encapsulated way to read the attribute — this always succeeds.
  4. Click Attempt Direct Access to try reading the private attribute directly from outside the class, bypassing the getter, and observe the access denial that actually occurs for the selected language.
  5. Compare the two Access Log entries side by side: the getter path (granted, emerald) versus the direct-access path (denied, rose).
  6. Switch languages and repeat — notice Java/C++ raise a compiler error, while Python raises a runtime AttributeError due to name mangling, not true enforcement.
