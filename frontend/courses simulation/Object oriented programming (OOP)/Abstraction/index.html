Theory: Abstraction

Abstraction hides complex implementation details behind a simple, well-defined interface. An abstract class declares methods that subclasses must implement, but cannot itself be instantiated — it exists only to be extended.

Java

Uses the abstract keyword and interface. Attempting new on an abstract class is a real compiler error.

Python

Uses ABC and @abstractmethod from the abc module. Instantiating the ABC raises a TypeError at runtime.

C++

A class with a pure virtual function (= 0) is abstract; declaring a variable of that type is a compile-time error.

Abstract Class Definitions — Multi-Language

Java

abstract class Shape {
  abstract void draw();
}
class Circle extends Shape {
  void draw() {
    System.out.println("Drawing Circle");
  }
}

Python

from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def draw(self): pass

class Circle(Shape):
    def draw(self):
        print("Drawing Circle")

C++

class Shape {
  public:
    virtual void draw() = 0;
};
class Circle : public Shape {
  public:
    void draw() {
      std::cout << "Drawing Circle";
    }
};

Abstract classes cannot be instantiated directly

A concrete subclass like Circle, which implements every abstract method, can be instantiated. But attempting new Shape() / Shape() directly always fails — this is enforced by the compiler (Java, C++) or the runtime (Python's abc module).
