Theory: Polymorphism (Method Overriding)

Polymorphism ("many forms") lets objects of different classes respond to the same method call in their own way. Method overriding is its runtime form: a subclass redefines a method it inherited with the exact same signature, and the version that actually executes depends on the object's real type at runtime.

Java

Uses dynamic method dispatch — the JVM looks up the actual object's class at runtime to decide which overridden method runs.

Python

Uses duck typing — any object with a matching method can be used polymorphically, no explicit hierarchy required.

C++

Requires the virtual keyword on the base method to enable runtime polymorphism through pointers/references.

Method Overriding — Multi-Language

Java

class Animal {
  void sound() { System.out.println("..."); }
}
class Dog extends Animal {
  void sound() { System.out.println("Bark"); }
}
Animal a = new Dog();
a.sound(); // "Bark" - runtime dispatch

Python

class Animal:
    def sound(self): pass

class Dog(Animal):
    def sound(self):
        print("Bark")

a = Dog()
a.sound()  # "Bark"

C++

class Animal {
  public: virtual void sound() {}
};
class Dog : public Animal {
  public: void sound() {
    cout << "Bark";
  }
};
Animal* a = new Dog();
a->sound(); // "Bark" - virtual dispatch
