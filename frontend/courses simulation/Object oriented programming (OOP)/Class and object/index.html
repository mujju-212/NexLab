Theory: Classes & Objects

Object-Oriented Programming organizes code around objects — self-contained bundles of data (attributes) and behavior (methods). A class is the blueprint that describes what attributes and methods its objects will have; an object is a concrete instance built from that blueprint, holding its own real values in memory.

class

A template/blueprint. It defines what attributes and methods every object built from it will have — but it is not itself a usable data value.

object

A concrete instance of a class, allocated in memory (typically the heap). Each object has its own independent copy of the class's attributes.

Class Definition & Instantiation — Multi-Language

Java

public class Student {
  String name;
  public Student(String n) {
    this.name = n;
  }
}
Student s1 = new Student("Alice");

Python

class Student:
    def __init__(self, name):
        self.name = name

s1 = Student("Alice")

C++

class Student {
  public:
    string name;
    Student(string n) { name = n; }
};
Student s1("Alice");

Core Pillars of OOP

  • Encapsulation: bundling data and the methods that act on it into one unit, restricting direct access.
  • Inheritance: deriving new classes from existing ones to reuse and extend behavior.
  • Polymorphism: letting different classes respond to the same method call in their own way.
  • Abstraction: hiding implementation details behind a simple, well-defined interface.

Simulator Procedure

  1. Open the Simulation tab and pick a language — Java, Python, or C++ — using the language pills.
  2. Study the Student class blueprint shown in the Code Panel: note the name attribute and the constructor.
  3. Click Instantiate Object to run the constructor and allocate a new object in heap memory.
  4. Inspect the new card in the Heap Memory panel — it shows a real memory address and the object's own name value.
  5. Click Instantiate Object again — observe that a second, independent object is created with its own memory slot and its own attribute value.
  6. Watch the Output Terminal log every instantiation event as it happens.
  7. Click Reset Heap to clear all instances and start again.
