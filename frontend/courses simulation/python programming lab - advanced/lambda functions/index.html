Theory: Anonymous Lambda Functions

A lambda function is an inline, anonymous function defined without the standard def keyword. It can take any number of arguments but may only evaluate a single expression, whose result is implicitly returned — no return statement is written or needed.

Single Argument

lambda x: x ** 2 — takes one input x and returns its square.

Multiple Arguments

lambda a, b: a + b — accepts comma-separated arguments, same as a normal function's parameter list.

Conditional (Ternary)

lambda a, b: a if a > b else b — a single expression can embed a full if/else via Python's conditional expression syntax.

Common Pitfalls

  • A lambda cannot contain statements — no for, while, multiple lines, or assignment statements, only one expression.
  • Overusing lambdas for complex logic hurts readability — if it needs a comment to explain, write a def function instead.
  • Assigning a lambda to a variable (sq = lambda x: x**2) works, but PEP 8 recommends using def for anything you plan to name and reuse.
  • Lambdas capture variables by reference, not value — be careful using them inside loops without a default-argument trick.

When to Use Lambda Functions

Sort keys — list.sort(key=lambda s: s["mark"]).
Higher-order calls — inline predicates/transforms for map(), filter(), reduce().
Short callbacks — one-off logic passed as a function argument, used once.
