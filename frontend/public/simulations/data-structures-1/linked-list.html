Theory: Singly Linked Lists

A singly linked list is a chain of nodes, each storing a value and a next pointer to the following node (or null at the end). A head pointer references the first node. Unlike arrays, insertion/deletion don't require shifting elements — only pointers change.

insertHead(value)

Create a new node whose next points to the current head, then move head to the new node. O(1) — no traversal needed.

insertTail(value)

Traverse until next === null (the tail), then attach the new node there. O(n) without a tail pointer.

delete(value)

Find the node just before the target and re-point its next to skip over the target — no shifting, just one pointer rewrite.

reverse()

Walk the list once, flipping each node's next to point backward using three pointers: prev, current, next. In-place, O(n) time, O(1) extra space.

Polynomial Representation & Addition

A polynomial like 5x⁴ + 3x² + 2 can be stored as a linked list of terms {coefficient, exponent, next}, kept sorted by descending exponent. Adding two polynomials merges their term lists: walk both lists with two pointers; when exponents match, add the coefficients (drop the term if the sum is 0); otherwise copy whichever term has the larger exponent and advance only that pointer.

OperationTime Complexity
insertHeadO(1)
insertTail / insertAt(pos)O(n)
delete(value) / search(value)O(n)
reverse()O(n) time, O(1) space
Polynomial addition (n, m terms)O(n + m)

Simulator Procedure

  1. Open Simulation and pick Mode: "List Operations" or "Polynomial Addition".
  2. List Operations: type a comma-separated op sequence, e.g. insertHead 10, insertTail 20, insertAt 15 1, search 15, delete 20, reverse.
  3. Polynomial Addition: enter each polynomial's terms as coefficient exponent pairs separated by commas, e.g. 5 4, 3 2, 2 0 means 5x⁴ + 3x² + 2.
  4. Click Start Simulation, then Step through pointer changes, or Run All to animate. The node highlighted in purple is the one being actively examined or rewired.
  5. During reverse, watch the orange curved arrows appear — they show pointers now running backward.
  6. Click Reset to clear the list and start over.
