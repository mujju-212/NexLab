Theory: Inheritance

Inheritance lets a new class (the subclass/child) derive attributes and methods from an existing class (the superclass/parent), enabling code reuse and expressing an "is-a" relationship — a Dog is an Animal.

Java

Uses the extends keyword. super() calls the parent constructor/methods. Java supports only single inheritance of classes.

Python

Uses parenthesis notation: class Dog(Animal):. Supports multiple inheritance directly.

C++

Uses : public Parent to inherit members, and also supports multiple inheritance.

Inheritance Syntax — Multi-Language

Java

class Animal {
  void eat() { System.out.println("eating"); }
}
class Dog extends Animal {
  void bark() { System.out.println("bark"); }
}
Dog d = new Dog();
d.eat();  // inherited
d.bark(); // own method

Python

class Animal:
    def eat(self):
        print("eating")

class Dog(Animal):
    def bark(self):
        print("bark")

d = Dog()
d.eat()   # inherited
d.bark()  # own method

C++

class Animal {
  public: void eat() { cout << "eating"; }
};
class Dog : public Animal {
  public: void bark() { cout << "bark"; }
};
Dog d;
d.eat();  // inherited
d.bark(); // own method

Key Terms

Single inheritance — one subclass, one parent class.
Multiple inheritance — a subclass derives from more than one parent (Python, C++ support this; Java does not for classes).
Method overriding — subclass redefines a parent's method with the same signature.
Diamond problem — ambiguity when two parents in multiple inheritance share a common ancestor method.
