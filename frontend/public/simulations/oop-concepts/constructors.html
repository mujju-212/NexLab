Theory: Constructors

A constructor is a special member function invoked automatically the moment an object is created. Its job is to initialize the object's attributes so the object is never left in an incomplete state.

Java

A method with the exact same name as the class, no return type. Java allows constructor overloading — multiple constructors with different parameter lists.

Python

Uses the __init__ special method. A class has exactly one __init__; default arguments simulate optional parameters.

C++

Same name as the class, optionally using a member initializer list (: name(n)) for efficient direct initialization.

Constructor Syntax — Multi-Language

Java

public class Student {
  String name;
  public Student(String n) {
    name = n;
  }
}
Student s1 = new Student("Alice");

Python

class Student:
    def __init__(self, name):
        self.name = name

s1 = Student("Alice")

C++

class Student {
  public:
    string name;
    Student(string n) : name(n) {}
};
Student s1("Alice");

Constructor Types

Default constructor — takes no parameters; sets attributes to standard initial values.
Parameterized constructor — accepts arguments used to initialize attributes with caller-supplied values.
Constructor overloading (Java/C++) — multiple constructors distinguished by parameter list.
Python's single __init__ — one initializer per class; optional params via default values emulate overloading.
