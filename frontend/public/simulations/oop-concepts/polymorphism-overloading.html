Theory: Polymorphism (Overloading)

Method overloading allows multiple methods in the same class to share a name but differ in parameter list (count/type). The correct version is chosen at compile time based on the arguments passed — this is why it's called compile-time (static) polymorphism.

Java

Directly supported — define several methods with the same name but different signatures.

Python

Not truly supported — see the important nuance below.

C++

Native support for function and method overloading, resolved by the compiler.

Important nuance: Python does NOT have true method overloading

If you define def add(self, a, b): ... and then def add(self, a, b, c): ... in the same Python class, the second definition simply replaces the first — Python keeps only the last method with a given name. There is no overload resolution at all. Python code that looks like overloading is really emulating it with default argument values or *args, e.g. def add(self, a, b, c=0). This lab's simulator reflects that honestly: Java/C++ show real overload resolution across distinct signatures; Python shows one flexible method with default parameters.

Overloading Syntax — Multi-Language

Java (true overloading)

class MathOps {
  int add(int a, int b) {
    return a + b;
  }
  int add(int a, int b, int c) {
    return a + b + c;
  }
}

Python (emulated only)

class MathOps:
    # Only ONE add() can exist —
    # default arg emulates overloading
    def add(self, a, b, c=0):
        return a + b + c

C++ (true overloading)

class MathOps {
  public:
    int add(int a, int b) {
      return a + b;
    }
    int add(int a, int b, int c) {
      return a + b + c;
    }
};

Simulator Procedure

  1. Open the Simulation tab and select a language pill — Java, Python, or C++.
  2. Read the code panel closely — for Python, note the comment explaining that only one add() can exist.
  3. Click Call add(2, 3) — two arguments — and observe which version of the method actually runs.
  4. Click Call add(2, 3, 4) — three arguments — and compare: in Java/C++ a genuinely different overloaded method runs; in Python the same single method runs with its default parameter filled in.
  5. Read the Execution Log message for each call — it states explicitly whether true overload resolution or default-argument emulation occurred.
