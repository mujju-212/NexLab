Theory: Sorting Algorithms

Sorting arranges data into a defined order (ascending here). This lab covers two very different strategies: Selection Sort, a simple comparison-based algorithm, and Radix Sort (LSD), a non-comparison, digit-based algorithm.

Selection Sort

On each pass i, scan the unsorted remainder [i..n-1] to find the minimum value, then swap it into position i. Repeats until the whole array is sorted. In-place, comparison-based, and not stable (a swap can reorder equal elements).

Radix Sort (LSD)

Sorts integers digit-by-digit, starting from the Least Significant Digit (units, then tens, then hundreds...). Each pass distributes numbers into 10 buckets (0–9) by the current digit using a stable bucket/counting distribution, then collects buckets 0→9 back into the array. No comparisons between elements are ever made.

AlgorithmBest CaseAverage CaseWorst CaseSpaceStable?
Selection SortO(n²)O(n²)O(n²)O(1)No
Radix Sort (LSD)O(d·(n+k))O(d·(n+k))O(d·(n+k))O(n+k)Yes

n = number of elements, d = number of digits in the largest number, k = radix base (10 for decimal digits). Selection Sort always performs exactly n(n-1)/2 comparisons regardless of input order — that's why best/average/worst are identical.

Why Radix Sort Has No Comparisons

Instead of asking "is A bigger than B?", radix sort repeatedly asks "what is this number's current digit?" and drops it straight into the matching bucket (0–9). Because each per-digit distribution is stable (elements with the same digit keep their relative order from the previous pass), after processing every digit — from least to most significant — the whole array ends up fully sorted.

Simulator Procedure

  1. Open the Simulation tab and choose Selection Sort or Radix Sort (LSD) from the algorithm dropdown.
  2. Pick a Quick Preset (Random, Nearly Sorted, Reverse Sorted, Duplicates) or leave the default array loaded.
  3. Click Start Simulation to load the trace at step zero.
  4. Click Step repeatedly to advance one comparison/swap (or one digit pass for Radix) at a time — watch the tiles slide into their new positions.
  5. Or click Run All to animate the entire sort automatically.
  6. For Radix Sort, the Digit Buckets panel shows which bucket (0–9) each value falls into on the current pass.
  7. Click Reset at any time to reload the current array and clear the trace.
