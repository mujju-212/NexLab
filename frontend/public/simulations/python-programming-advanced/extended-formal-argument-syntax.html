Theory: Extended Formal Argument Syntax

Python lets a function accept an arbitrary number of arguments using extended formal argument syntax. The single-asterisk form *args packs extra positional arguments into a tuple; the double-asterisk form **kwargs packs extra keyword arguments into a dictionary.

*args

Packs variable non-keyword arguments into an immutable tuple: def add(*args): .... Lets a function accept any quantity of positional parameters.

**kwargs

Packs variable named keyword arguments into a dictionary: def info(**kwargs): .... Access parameters through key lookups.

Parameter Order

Strict declaration sequence: standard positional arguments, then *args, then default/keyword-only parameters, and finally **kwargs.

SyntaxCall exampleInside the function
*argsfunc(1, 2, 3)args = (1, 2, 3) — type: tuple
**kwargsfunc(a=1, b=2)kwargs = {'a': 1, 'b': 2} — type: dict
Unpackingfunc(*my_list) / func(**my_dict)Spreads a container's items directly into the call

Common Pitfalls

  • The names args and kwargs are convention, not syntax — the asterisks (*, **) are what matter, not the identifier names.
  • **kwargs must come after *args in a function signature — reversing the order is a SyntaxError.
  • You cannot pass a keyword argument twice — func(x=1, **{'x': 2}) raises a TypeError for a duplicate argument.
  • Unpacking a dict with **d requires every key to be a valid, matching keyword argument name.
