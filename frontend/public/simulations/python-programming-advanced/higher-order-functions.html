Theory: Higher-Order Functions in Python

A Higher-Order Function is a function that either accepts one or more functions as arguments, or returns a function as its result. Because Python treats functions as first-class citizens (they can be assigned to variables, stored in lists, or passed around like any other value), built-ins like map(), filter(), and reduce() enable a clean, functional style of programming.

map(func, iterable)

Applies func to every item of an iterable and returns an iterator of transformed values, one-to-one. map(lambda x: x*2, nums).

filter(pred, iterable)

Selects items for which the boolean predicate returns True, discarding the rest. filter(lambda x: x%2==0, nums).

reduce(func, iterable)

From functools. Applies a two-argument function cumulatively, left to right, collapsing the whole sequence into one value. reduce(lambda a,b: a+b, nums).

FunctionInput → Output shapeTypical use
map()N items → N items (transformed)Scaling, formatting, type conversion
filter()N items → ≤N items (subset)Validation, search, cleaning data
reduce()N items → 1 valueTotals, products, running aggregates

Common Pitfalls

  • map() and filter() return iterators, not lists — wrap with list(...) to see or reuse the values.
  • reduce() is not a built-in in Python 3 — you must from functools import reduce first.
  • A cumulative product via reduce(lambda a,b: a*b, nums) only equals a factorial when nums happens to be a consecutive run 1..N — it is a general multiplication reduction, not a factorial-specific operator.
  • Prefer a list/generator comprehension over map()/filter() when readability matters — both approaches are equally "Pythonic".

Patterns Covered in This Lab

Transformation — squaring every element with map() + lambda.
Selection — keeping only even numbers with filter() + lambda.
Reduction — collapsing a list to a single cumulative product with reduce() + lambda.
