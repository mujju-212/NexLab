Theory: Python Strings, Slicing & Immutability

A Python string (str) is an immutable sequence of Unicode characters, written with single quotes, double quotes, or triple quotes. Strings support indexing, slicing, concatenation, substring searching, and a rich set of built-in methods.

Indexing 0-Based

Access characters with s[i]. Positive indices start from 0 (left to right); negative indices start from -1 (right to left).

Slicing s[start:stop:step]

Extracts a substring with s[start:stop:step]. stop is exclusive: "Python"[0:2] → "Py".

Immutability Immutable

Characters cannot change in place. s[0] = 'X' raises TypeError. Every string operation returns a new string.

String Methods str Methods

upper(), lower(), replace(old,new), split(delim), strip().

f-String Formatting f"..."

Embed expressions directly inside braces: f"Hello {name}, score: {score}".

Substring Search find() / in

Check presence with 'Py' in 'Python' (True) or locate with s.find('th') (returns index, or -1).

Common Pitfalls

  • Slicing never raises IndexError even with out-of-range bounds ("Py"[0:99] just returns "Py"), but direct indexing does ("Py"[99] raises IndexError).
  • Strings are immutable — methods like .upper() or .replace() always return a NEW string; they never modify the original in place.
  • .find() returns -1 on failure, not an exception — but .index() raises ValueError if the substring isn't found. Easy to mix them up.
  • f-strings evaluate expressions at format time, not creation time — if a variable inside f"{x}" changes later, the already-created string does NOT update.
