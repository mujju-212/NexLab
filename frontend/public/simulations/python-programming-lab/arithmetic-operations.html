Theory: Python Arithmetic Operators

Python provides seven standard arithmetic operators for numeric computation on int, float, and (indirectly) complex values. Each operator follows precise typing and rounding rules that differ from most other languages — especially % and // on negative numbers.

+ Addition

Adds two values. 10 + 3 = 13. Result is float if either operand is a float literal, otherwise int.

- Subtraction

Subtracts right operand from left. 10 - 3 = 7. Same int/float rule as addition.

* Multiplication

Multiplies two numbers. 10 * 3 = 30. Same int/float rule applies.

/ True Division

Always returns a float, even for exact divisions. 10 / 2 = 5.0, not 5.

// Floor Division

Divides and rounds toward negative infinity (not toward zero). 10 // 3 = 3, but -7 // 3 = -3.

% Modulus

Returns the remainder, with the same sign as the divisor ("floored" modulo). 10 % 3 = 1, but -7 % 3 = 2.

** Exponentiation

Raises the left operand to the power of the right. 2 ** 8 = 256. Right-associative: 2 ** 3 ** 2 evaluates as 2 ** (3 ** 2) = 512, not (2 ** 3) ** 2.

Common Pitfalls

  • Modulo is NOT truncated remainder. Many languages (C, JavaScript) give -7 % 3 == -1. Python gives -7 % 3 == 2 because the result always takes the sign of the divisor. Compute it as ((a % b) + b) % b if you need to derive it manually.
  • Floor division floors, it doesn't truncate. -7 // 3 = -3 (rounds down to negative infinity), not -2 (which would be truncation toward zero).
  • / always returns float — 4 / 2 is 2.0, not 2. This can silently change downstream type-dependent logic.
  • Division/modulus by zero raises ZeroDivisionError — Python never silently returns Infinity or NaN for ints/floats the way some languages do.
