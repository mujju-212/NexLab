Theory: Python Built-in Functions

Python ships with a set of built-in functions that are always available in every script without an import statement. They cover math, sequence manipulation, type inspection/conversion, and I/O — and knowing them well means writing far less boilerplate code.

Mathematical Math

abs(x) absolute value, pow(x,y) power, round(x,n) rounding, max(...) / min(...).

Sequence Utilities Sequences

len(seq) length, sum(seq) total, sorted(seq) new sorted list, reversed(seq) reverse iterator.

Char & Type Functions Conversion

ord(ch) character → code, chr(code) code → character, type(obj) class inspection.

FunctionPurposeExample
abs(x)Absolute (non-negative) valueabs(-42) → 42
pow(x,y)x raised to power ypow(2,5) → 32
max()/min()Largest / smallest of argumentsmax(10,85,45) → 85
sum(seq)Total of an iterablesum([40,10,90]) → 140
sorted(seq)New sorted list (original untouched)sorted([3,1,2]) → [1,2,3]
ord(ch) / chr(n)Character ⇌ Unicode code pointord('A') → 65, chr(66) → 'B'

Common Pitfalls

  • sorted() vs list.sort(): sorted() returns a brand-new list; .sort() mutates in place and returns None. Printing the result of .sort() is a classic beginner bug.
  • ord() only accepts a single character. Passing a multi-character string raises a TypeError.
  • max()/min() on an empty sequence raise a ValueError unless a default= argument is given.
  • round() uses banker's rounding (round-half-to-even): round(2.5) == 2, not 3 — surprising for newcomers used to "round half up".
