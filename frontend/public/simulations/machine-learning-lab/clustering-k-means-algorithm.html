Theory: Unsupervised K-Means Clustering

K-Means partitions $N$ unlabeled points into $K$ clusters, each represented by a Centroid $\mu_k$, by alternating an Expectation step (assign points) and a Maximization step (recompute centroids) until convergence.

Inertia (WCSS)

$J = \sum_k \sum_{x \in S_k} \|x-\mu_k\|^2$ — the cost function K-Means minimizes.

E-Step / M-Step

E: assign each point to its nearest centroid. M: recompute each centroid as the mean of its assigned points.

The Elbow Method

Plotting Inertia vs $K$ shows a steep decline followed by a bend — the "elbow" suggests a good value of $K$.

Random vs. K-Means++ Initialization

Standard random initialization picks starting centroids uniformly at random and can get stuck in poor local minima if two centroids happen to start close together. K-Means++ spreads initial centroids apart proportional to squared distance, giving faster and more reliable convergence. Because initialization is random, running K-Means twice with init='random' on the same data can produce different starting centroid positions — and this simulator now genuinely reflects that.

The Elbow Curve Must Reflect the Actual Data

An Elbow-Method plot is only useful if its inertia values are genuinely computed by running K-Means for $K=1$ through $6$ on the dataset currently loaded (including any points you've clicked to add). This simulator recomputes the curve live every time the dataset or points change.

Simulator Procedure

  1. Select a Spatial Dataset (3 Blobs, 4 Overlapping Clusters, or Concentric Rings) or click a Quick Preset.
  2. Choose K and Initialization (k-means++ or random). Try running the random strategy twice in a row on the same dataset — the starting centroid positions will genuinely differ each time.
  3. Click Start Simulation to seed initial centroids.
  4. Click Step Iteration to watch the Expectation (assignment) and Maximization (centroid shift) steps.
  5. Watch the Elbow Method curve — it is computed live from the current dataset by actually running K-Means for K=1..6.
  6. Click anywhere on the canvas to add a custom point and re-cluster dynamically.
