Theory: Naïve Bayes Classification & Bayes' Theorem

Naïve Bayes is a probabilistic classifier based on Bayes' Theorem, computing the posterior probability of a class $y$ given features $X$. It is "naïve" because it assumes all features are conditionally independent given the class.

P(Y|X) = P(X|Y)·P(Y) / P(X) = P(Y)·∏P(xi|Y) / P(X)

Posterior ∝ Prior × Likelihood Product

Prior P(Y)

Baseline class probability before seeing any features: Count(Y)/Total.

Likelihood P(x|Y)

Conditional probability of feature $x$ given class $Y$ — for text, the relative frequency of a word within that class's documents.

Laplace Smoothing (α)

Prevents the zero-frequency problem by adding pseudo-counts to every word, known or unseen.

P(xi|Y) = (Count(xi,Y) + α) / (Count(Y) + α·|V|)

Variants of Naïve Bayes

  • MultinomialNB — discrete word counts / term frequency (text classification).
  • CategoricalNB — categorical discrete features (e.g. Weather: Sunny, Rainy, Overcast).
  • GaussianNB — continuous numerical features assumed normally distributed.

Worked Example — α Genuinely Changes Known-Word Likelihoods

Suppose the word "free" appears 40 times among 203 total spam-class word tokens, over a 10-word vocabulary. At α=0.5: P(free|spam) = (40+0.5)/(203+0.5×10) = 40.5/208 ≈ 0.195. At α=2.0: P(free|spam) = (40+2)/(203+2×10) = 42/223 ≈ 0.188. The simulator recomputes this live for every word, known or unseen, every time α changes — nothing is hardcoded.
