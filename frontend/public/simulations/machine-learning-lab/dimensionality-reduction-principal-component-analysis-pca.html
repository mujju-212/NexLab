Theory: Principal Component Analysis

PCA finds new axes — principal components — that are ordered by how much variance of the data they capture. The first principal component (PC1) points in the direction of maximum spread; the second (PC2) is orthogonal to it and captures the remaining spread. Projecting data onto only the top component(s) reduces dimensionality while keeping as much information (variance) as possible.

1. Centering

Subtract each feature's mean: x̄, ȳ. Centered data x' = x − x̄ has mean zero, which is required before computing covariance.

2. Covariance matrix

Cov = [[Σx'²/(n−1), Σx'y'/(n−1)], [Σx'y'/(n−1), Σy'²/(n−1)]]. Diagonal entries are the per-feature variances; the off-diagonal entry is the covariance between the two features.

3. Eigenvalues (closed form)

For symmetric [[a,b],[b,d]]: λ = (a+d)/2 ± √(((a−d)/2)² + b²). Each eigenvalue is the variance captured along its eigenvector's direction.

4. Eigenvectors

Solving (A − λI)v = 0 for a 2×2 symmetric matrix gives v ∝ [b, λ−a] (normalized), or the coordinate axes directly when b = 0.

5. Explained variance ratio

ratio_i = λᵢ / (λ₁+λ₂). Tells you what fraction of total variance each principal component accounts for — the basis for deciding how many components to keep.

6. Projection & reconstruction

1-D projection: projᵢ = x'ᵢ · ev1. Reconstruction: x̂ᵢ = mean + projᵢ · ev1. Using only PC1 is lossy (unless λ₂ ≈ 0); using both components reconstructs the original data exactly.

Why reduce dimensionality?

When features are correlated, most of the information can be captured by fewer directions than the original number of features. PCA finds the smallest set of new (uncorrelated) axes that keeps most of the variance, which speeds up downstream models, reduces noise, and makes data easier to visualize.

Simulator Procedure

  1. Open the Simulation tab and choose a Dataset from the dropdown, or click a Quick Preset.
  2. Click Start to plot the raw 2-D scatter with its centroid.
  3. Click Step repeatedly (or Run All) to walk through: centering → covariance matrix → eigenvalues/eigenvectors → explained variance → projection animation → reconstruction.
  4. At the eigen-decomposition step, watch the two principal-axis lines drawn through the centroid — their length is scaled by √λ, so the dominant axis is visibly longer.
  5. At the final step, watch every point genuinely animate from its original 2-D position onto the PC1 line — this is the actual 1-D projection, not a canned animation.
  6. Compare datasets: highly-correlated presets collapse almost losslessly onto PC1 (explained variance near 100%); the uncorrelated preset visibly loses information when collapsed.
  7. Click Reset at any time to clear and start over.
