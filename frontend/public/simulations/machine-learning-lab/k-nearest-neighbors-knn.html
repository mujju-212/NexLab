Theory: k-Nearest Neighbors (KNN) & Distance Metrics

k-Nearest Neighbors is a non-parametric, instance-based ("lazy learning") algorithm. It never learns explicit parameters ($w, b$) — instead it stores the entire training set and, at query time, computes distances from a new point to every stored point, then votes among the $k$ closest.

Euclidean: d(x,y) = √Σ(xi−yi)²

Manhattan: d(x,y) = Σ|xi−yi|

Choice of k

Small k (e.g. 1) is sensitive to noise (overfitting). Large k smooths boundaries but risks underfitting. Odd k avoids ties in binary classification.

Distance Metrics

Euclidean (L2) measures straight-line distance. Manhattan (L1) measures grid/city-block distance along axes. Feature scaling matters for both.

Majority Voting

Among the k nearest neighbors, the query point is assigned the most frequent class label.

The Curse of Dimensionality

As feature count grows, the volume of space grows exponentially and all points start looking equidistant, weakening distance-based methods. Feature selection or dimensionality reduction (e.g. PCA) helps preserve KNN's effectiveness.

Why the Radius Circle Must Respect Both Axes

When a canvas plots two features with very different numeric ranges (e.g. Sepal Length 4–7 vs Petal Length 1–5), the pixels-per-unit scale differs on each axis. A true circle of Euclidean radius $r$ in data space becomes an ellipse in pixel space once each axis is scaled independently. Drawing it as a perfect pixel-circle using only one axis's scale would visually mislead students about which points are truly "within radius r." This simulator now draws the correct ellipse using both axis scales.

Simulator Procedure

  1. Select a Classification Dataset (Iris Subset, Customer Churn, or Credit Loan Risk) or click a Quick Preset.
  2. Set Neighbors (k) and the Distance Metric (Euclidean or Manhattan).
  3. Click anywhere on the canvas to place the orange Query Point.
  4. Click Start Simulation to compute distances from every training point to the query.
  5. Click Step Epoch to trace the code and watch the neighborhood ellipse, connecting lines, and vote tally update.
  6. Review the majority vote tally and predicted class in the result banner.
