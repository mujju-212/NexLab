Theory: Random Forest & Ensemble Learning

A Random Forest is an Ensemble of Decision Trees combined via Bagging (Bootstrap Aggregating) and the Random Subspace Method. Aggregating predictions from many decorrelated trees reduces variance and overfitting compared to a single tree.

Bagging

Each tree trains on a bootstrap sample (drawn with replacement). Unselected samples (~36.8%) form the Out-Of-Bag (OOB) set for unbiased validation.

Random Subspace

At each split, only a random subset of features ($\sqrt{M}$ typical for classification) is considered, decorrelating trees.

Majority Vote

$\hat{y} = \text{mode}(\hat{y}_1,...,\hat{y}_B)$ — the final prediction is whichever class the most trees voted for.

Why Random Forest Outperforms a Single Tree

A single tree has high variance and easily overfits noise. Averaging many decorrelated trees reduces variance without increasing bias much — the mathematical reason bagging works.

The Announced Label Must Match the Actual Tally

If 5 trees vote and 3 say "Approved" while 2 say "Default Risk", the forest MUST announce "Approved" — the class with the most votes. This simulator tallies the votes of exactly the trees currently selected by n_estimators and always announces whichever class actually won that count, so changing the number of trees can genuinely flip the announced prediction.

Simulator Procedure

  1. Select a Dataset (Loan Default, Heart Disease, or Wine Quality) or click a Quick Preset.
  2. Configure Number of Trees (n_estimators) and Max Features.
  3. Click Start Simulation to generate bootstrap datasets and initialize the trees.
  4. Click Step Epoch to trace training, feature importance aggregation, and the final majority vote.
  5. Try changing n_estimators (3 vs 5 vs 7) on the Wine Quality preset — watch the announced label genuinely change because the vote tally changes with the number of trees included.
  6. Click Run / Execute All to complete training instantly.
