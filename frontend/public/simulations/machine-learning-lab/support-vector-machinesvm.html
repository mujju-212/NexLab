Theory: Support Vector Machines

A Support Vector Machine finds the hyperplane w·x + b = 0 that separates two classes while maximizing the margin — the gap between the hyperplane and the nearest points of each class. Points that sit exactly on that margin boundary are called support vectors, because they alone determine the hyperplane's position; every other point could move without changing the solution.

Decision function

A new point x is classified by the sign of f(x) = w·x + b. If f(x) ≥ 0 → class +1, else class −1. The magnitude |f(x)| reflects confidence / distance from the boundary.

Margin width = 2 / ‖w‖

The two margin hyperplanes w·x+b = +1 and w·x+b = −1 are parallel to the boundary, each offset by 1/‖w‖. A smaller ‖w‖ means a wider margin.

Hinge loss

L(x,y) = max(0, 1 − y(w·x+b)). Zero when a point is correctly classified beyond the margin; grows linearly the further a point violates the margin. It is not differentiable at the kink, so training uses a subgradient.

Regularization constant C

The full objective is min (1/2)‖w‖² + C·Σ hinge. Small C prioritizes a wide margin (tolerates some violations = "soft margin"). Large C penalizes violations heavily, forcing a narrower, stricter margin ("hard margin").

Training by Subgradient Descent

On every epoch this lab computes the true subgradient of the objective over the whole training set and updates the weights:

∇w = w − C · Σi: yᵢ(w·xᵢ+b)<1 yᵢxᵢ (only margin-violating points contribute)
∇b = − C · Σi: yᵢ(w·xᵢ+b)<1 yᵢ
w ← w − η·∇w , b ← b − η·∇b (η = learning rate)

A point is treated as a support vector once training converges if its functional margin yᵢ(w·xᵢ+b) is close to exactly 1 (within a small tolerance) — i.e. it lies right on the margin boundary. This lab computes that condition from the actual trained w, b every time — it never hardcodes which points are support vectors.

Simulator Procedure

  1. Open the Simulation tab. The fixed 10-point training set (5 points of class −1 near (2,2), 5 points of class +1 near (6,6)) is plotted immediately.
  2. Choose a Regularization C value, a Learning Rate, and a Kernel (Linear or Polynomial deg-2), or click a Quick Preset.
  3. Click Start Training to reset w = 0, b = 0 and enable stepping.
  4. Click Step Epoch to run one real subgradient-descent update and watch the boundary/margins move on the canvas, or click Run All to animate all epochs automatically.
  5. Watch the Model State panel — ‖w‖, margin width, and accuracy are recomputed every epoch, not fixed.
  6. After training, inspect the Support Vectors list — it is derived from the final w,b by checking which points have functional margin ≈ 1.
  7. Change C and retrain to see the margin width and boundary genuinely shift. Click Reset to clear and start over.
