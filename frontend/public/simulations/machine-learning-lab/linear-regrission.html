Theory: Linear Regression & Gradient Descent

Linear Regression models a linear relationship between an input $x$ and a continuous target $y$ using the hypothesis $\hat{y} = w \cdot x + b$, where $w$ is the slope (weight) and $b$ is the intercept (bias). There are two ways to find the best $w,b$: the closed-form Ordinary Least Squares (OLS) solution, and the iterative Gradient Descent optimizer used here.

&yhat; = w·x + b   |   J(w,b) = (1/n) Σ (yi − &yhat;i)²   |   w ← w − α·∂J/∂w,  b ← b − α·∂J/∂b

Cost Function (MSE)

Average squared error between actual and predicted targets. Gradient Descent's entire job is to push this value toward its minimum.

Gradient Descent

dw = -2/n Σ x(y−&yhat;), db = -2/n Σ(y−&yhat;). Every epoch nudges $w,b$ opposite the gradient direction.

R² Coefficient

$R^2 = 1 - SS_{res}/SS_{tot}$, the proportion of variance in $y$ explained by $x$. Ranges roughly $0$ (no fit) to $1$ (perfect fit).

MethodHow it finds w, bScales to big data?
Closed-form OLSSolves the normal equations directly — exact, one shot.Expensive for many features (matrix inversion).
Gradient DescentIteratively steps opposite the cost gradient until convergence.Yes — used for large datasets / neural networks.

Role of the Learning Rate (α)

Too small an α converges extremely slowly (needs many more epochs to approach the minimum). Too large an α overshoots the minimum and can diverge entirely. The simulator below runs genuine gradient descent on standardized features (for numerical stability) and converts the learned parameters back to the original scale — so a smaller learning rate visibly needs more epochs to catch up to the OLS answer, exactly as theory predicts.

Worked Example

For points (1,2), (2,4), (3,6): OLS gives w=2, b=0 (a perfect fit, R²=1.0). Gradient Descent starting at w=0,b=0 with α=0.1 will compute dw = -2/3Σx(y-&yhat;) = -2/3(1·2+2·4+3·6) = -18.67 on the very first epoch, then update w ← 0-0.1×(-18.67)=1.867 — already close to the optimum after just one step.

Simulator Procedure

  1. Select a Dataset (Salary vs Experience, House Price vs Area, or Exam Score vs Study Hours) or click a Quick Preset.
  2. Choose a Learning Rate (α) — 0.01 (standard), 0.05 (fast), or 0.001 (conservative).
  3. Click Start Simulation to plot the raw data points onto the regression canvas.
  4. Click Step Epoch to trace real gradient descent snapshots — each displayed w, b is genuinely computed from that epoch's parameters, not interpolated.
  5. Watch the regression line and residual error segments update, and compare the live R²/MSE against the closed-form OLS answer shown in the terminal.
  6. Click Run / Execute All to animate the full training run, or Reset to start over.
