Theory: Q-Learning

Q-Learning is a model-free reinforcement learning algorithm — unlike Value/Policy Iteration, the agent does not know the reward function or transition model in advance. It learns purely from experience: try an action, observe the reward and next state, and update an estimate.

Q(s,a) ← Q(s,a) + α · [ r + γ · maxa' Q(s',a') − Q(s,a) ]

This is the Temporal-Difference (TD) update. The bracketed term r + γ·max Q(s',a') − Q(s,a) is the TD error — the difference between what we just observed (immediate reward plus our best current estimate of the future) and what we previously believed Q(s,a) was worth. α (learning rate) controls how much we trust this one new observation over our old estimate.

ε-greedy action selection

With probability ε, pick a uniformly random action (explore); otherwise pick argmaxa Q(s,a) (exploit current knowledge). Without exploration the agent could get stuck always repeating a mediocre path it found early on.

Why Q-Learning is "off-policy"

The update uses max_a' Q(s',a') — the BEST possible next action — regardless of which action the ε-greedy policy actually takes next. It learns the optimal Q-function even while behaving partly randomly.

Worked Micro-Example

Agent is one cell left of the goal. All Q-values start at 0. α=0.3, γ=0.9. It takes action "right", lands on the goal, and receives reward r=+1 (episode ends, so no bootstrap term for a terminal next-state):

Q(s,right) ← 0 + 0.3 · [1 + 0.9·0 − 0] = 0.3

Next time the agent visits this same cell and tries "right" again, reaching the goal again gives: Q ← 0.3 + 0.3·[1 − 0.3] = 0.51. Each visit nudges Q(s,"right") closer to its true value (~1.0) — this is why Q-Learning needs MANY episodes before the table stabilises.

Q-Learning (model-free)Value/Policy Iteration (model-based)
No knowledge of R(s) or transition function needed — learns purely from sampled (s,a,r,s') experience.Requires the full reward function and transition model to sweep every state exactly.
Needs many episodes; convergence is noisy and gradual.Converges in a small, predictable number of sweeps/cycles.
Works when the environment is unknown or too large to model exactly (most real-world robotics/game AI).Only usable when the full MDP is known and small enough to sweep.

Simulator Procedure

  1. Open the Simulation tab, pick a Quick Preset grid, and set α (learning rate), γ (discount) and ε (exploration rate).
  2. Click Start to zero the Q-table and place the agent (●) at the start cell.
  3. Click Step (1 Action) to take a single ε-greedy action — watch the agent move, the TD update printed in the terminal, and that cell's Q-values change.
  4. Click Run 1 Episode to animate steps automatically until the agent reaches the goal or pit.
  5. Click Fast-Train 100 Episodes to run many episodes instantly (no animation) — the running average "steps to goal" chart shows learning progress at a glance.
  6. Each cell shows its best learned action as an arrow, and the max Q-value for that cell — this is the greedy policy implied by the current Q-table.
  7. Click Reset to wipe the Q-table and start learning from scratch.
